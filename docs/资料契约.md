# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## shops

独立门店归总店。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 门店 |
| `head` | string | 总店 |
| `district` | string | 商圈 |

## promises

承诺各自适用，不预置判定结果。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 承诺 |
| `shop` | string | 门店 |
| `kind` | string | 退款时效或调解服务 |
| `channel` | string | 适用渠道 |
| `start_day` | integer | 起 |
| `end_day` | integer | 止 |
| `deadline_days` | integer | 时限 |
| `goods_state` | string | 允许商品状态 |

显式引用：`shop` → `shops.id`。

## requests

同消费请求可能多次联系；编号保留实际来源。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 记录 |
| `request` | string | 独立消费请求 |
| `shop` | string | 责任门店 |
| `handling_shop` | string | 办理门店 |
| `purchase_day` | integer | 消费日 |
| `entered_day` | integer | 进入日 |
| `channel` | string | 渠道 |
| `goods_state` | string | 商品状态 |
| `amount_cents` | integer | 消费金额 |
| `kind` | string | 诉求 |

显式引用：`shop` → `shops.id`；`handling_shop` → `shops.id`。

## events

商家自报与实际回执分别保留。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 事件 |
| `request` | string | 消费请求 |
| `kind` | string | 协商或转总店或退款到账或撤回或调解结项 |
| `day` | integer | 实际日 |
| `source` | string | 来源 |
| `state` | string | 确认或争议 |

## metric_definitions

编辑登记的业务定义；无执行器或预置统计。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 口径 |
| `concept` | string | 业务概念 |
| `numerator` | string | 分子定义 |
| `denominator` | string | 分母定义 |
| `time_basis` | string | 时间归属 |
| `dimensions` | array | 允许维度 |
| `effective_day` | integer | 生效日 |

## reviews

复核不删除请求事实。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 复核 |
| `target` | string | 目标 |
| `kind` | string | 回执撤销或门店更正 |
| `finding` | string | 采用事实 |
| `known_day` | integer | 知悉日 |

## publications

历史公开内容。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 发布 |
| `metric` | string | 口径 |
| `shop` | string | 门店 |
| `day` | integer | 发布日 |
| `content` | string | 原文 |

显式引用：`metric` → `metric_definitions.id`；`shop` → `shops.id`。

## privacy_rules

组合查询保护，极值金额另作受限事实。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 配置 |
| `min_requests` | integer | 最小独立请求数 |
| `amount_bands` | array | 可公布金额层上界分 |
